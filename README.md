# XO Gobble 
เกมกระดานบนคอนโซลที่เขียนด้วยภาษา C++ ซึ่งได้แรงบันดาลใจจากเกม Gobblet Gobblers พร้อมการเพิ่มกติกาพิเศษ ในเกมนี้ผู้เล่นสามารถวางหมากที่มีขนาดใหญ่กว่าทับหมากที่เล็กกว่าได้ และหมากที่ถูกทับไว้นานเกินไปจะถูกลบออกจากเกมอย่างถาวร

## สิ่งที่ต้องมีเบื้องต้น (Prerequisites)
* คอมไพเลอร์ C++ ที่รองรับ C++11 ขึ้นไป (เช่น GCC, Clang, MSVC)
* ระบบปฏิบัติการ Windows (เนื่องจากโค้ดมีการใช้ `<windows.h>` สำหรับการตั้งค่าการแสดงผลภาษาไทยแบบ UTF-8 บนคอนโซล)

## วิธีการคอมไพล์และรันโปรแกรม
1. เปิด Terminal หรือ Command Prompt
2. คอมไพล์ซอร์สโค้ดด้วยคอมไพเลอร์ C++ ตัวอย่างเช่น หากใช้ g++:
   `g++ -o gobblet_game main.cpp`
3. รันไฟล์ที่คอมไพล์แล้ว:
   `./gobblet_game` (หรือ `gobblet_game.exe` บน Windows)

## วิธีการเล่น

เป้าหมายคือการเป็นผู้เล่นคนแรกที่สามารถเรียงหมากของตนเองให้ติดกัน 3 ตัวได้สำเร็จ (ไม่ว่าจะเป็นแนวนอน แนวตั้ง หรือแนวทแยง)

### องค์ประกอบของเกม
* **ผู้เล่น:** มี 2 คน คือ Player X และ Player O
* **กระดาน:** ตารางขนาด 3x3
* **หมาก:** ผู้เล่นแต่ละคนจะเริ่มต้นด้วยหมากในมือ 6 ตัว ดังนี้:
  * ขนาดเล็ก (S) 2 ตัว
  * ขนาดกลาง (M) 2 ตัว
  * ขนาดใหญ่ (L) 2 ตัว

### กติกาและระบบเกมเพลย์
1. **การกระทำในแต่ละตา:** เมื่อถึงตาของคุณ คุณต้องเลือกทำอย่างใดอย่างหนึ่งดังต่อไปนี้:
   * **วางหมากตัวใหม่:** เลือกหมากจากในมือแล้ววางลงบนกระดาน
   * **ย้ายหมากที่มีอยู่:** ย้ายหมากของคุณที่วางอยู่บนสุดของช่องใดช่องหนึ่งไปยังช่องอื่น
2. **การทับหมาก (Gobbling):** คุณสามารถวางหรือย้ายหมากไปยังช่องว่าง หรือทับบนหมากที่มีขนาดเล็กกว่าได้ (เช่น หมากขนาดกลางทับหมากขนาดเล็กได้ หมากขนาดใหญ่ทับได้ทั้งขนาดกลางและขนาดเล็ก)
3. **กฎการตายของหมาก (Suffocation Rule):** หากหมากตัวใดถูกหมากตัวอื่นทับไว้นานติดต่อกันเกิน 3 ตา หมากตัวนั้นจะถูกนำออกจากเกมอย่างถาวร
4. **รูปแบบการป้อนข้อมูล (Input):** เมื่อระบบถามหาตำแหน่ง ให้พิมพ์เลขแถวและคอลัมน์เป็นตัวเลขสองตัวติดกัน (0-2) เช่น `11` คือตำแหน่งตรงกลางกระดาน และ `02` คือมุมขวาบน

## โครงสร้างโค้ดและคำอธิบายฟังก์ชัน

โปรเจกต์นี้เขียนขึ้นโดยยึดหลักการเขียนโปรแกรมเชิงวัตถุ (OOP) ในภาษา C++ ด้านล่างนี้คือคำอธิบายของแต่ละคลาสและฟังก์ชันที่เกี่ยวข้อง

### ฟังก์ชันระดับโกลบอล (Global Functions)
* `clearScreen()`: ใช้สำหรับล้างหน้าจอคอนโซล โดยเรียกใช้คำสั่ง `cls` สำหรับ Windows และ `clear` สำหรับระบบปฏิบัติการอื่น เพื่อรีเฟรชหน้าจอ UI
* `sizeToString(Size s)`: ฟังก์ชันตัวช่วยในการแปลงค่า Enum ของ `Size` (SMALL, MEDIUM, LARGE) ให้เป็นข้อความตัวอักษร ("S", "M", "L")

### คลาส: Piece
ทำหน้าที่เป็นตัวแทนของหมากแต่ละตัวในเกม
* `Piece(string c, Size s)`: คอนสตรัคเตอร์สำหรับกำหนดค่าเริ่มต้นให้หมาก โดยรับค่าสี (X หรือ O) และขนาด
* `getSize()`: คืนค่าขนาดของหมาก
* `getColor()`: คืนค่าสี (เจ้าของ) ของหมาก
* `getCoveredTurns()`: คืนค่าจำนวนตาที่หมากตัวนี้ถูกทับอยู่
* `incrementCoveredTurn()`: เพิ่มตัวนับจำนวนตาที่ถูกทับขึ้น 1
* `resetCoveredTurn()`: รีเซ็ตตัวนับจำนวนตาที่ถูกทับเป็น 0 (ใช้เมื่อหมากที่ทับอยู่ด้านบนถูกย้ายออกไป)
* `getDisplay()`: คืนค่าข้อความที่จัดรูปแบบแล้วสำหรับการแสดงผลบนคอนโซล พร้อมใส่รหัสสี ANSI

### คลาส: Cell
ทำหน้าที่จัดการช่อง 1 ช่องบนตาราง 3x3 คลาสนี้จะจัดการหมากในรูปแบบของชั้นข้อมูล (Stack) เนื่องจากหมากหลายตัวสามารถซ้อนทับกันในช่องเดียวได้
* `hasPiece()`: ตรวจสอบว่าช่องนี้มีหมากวางอยู่หรือไม่
* `getTopPiece()`: คืนค่าข้อมูลหมากที่อยู่บนสุด (หมากที่มองเห็นได้)
* `pushPiece(const Piece& p)`: พยายามวางหมากลงในช่อง โดยจะตรวจสอบว่าช่องนั้นว่าง หรือหมากตัวใหม่มีขนาดใหญ่กว่าหมากที่อยู่บนสุดจริงหรือไม่ คืนค่า true หากวางสำเร็จ
* `popTopPiece()`: นำหมากที่อยู่บนสุดออกจากช่องและคืนค่าข้อมูลหมากนั้น พร้อมทั้งรีเซ็ตตัวนับจำนวนตาที่ถูกทับให้กับหมากตัวล่างที่ถูกเปิดเผยขึ้นมาใหม่
* `updateCoveredPiecesTurn()`: วนลูปตรวจสอบหมากทุกตัวที่อยู่ในช่องนี้ (ยกเว้นตัวบนสุด) และบวกค่าตัวนับจำนวนตาที่ถูกทับเพิ่มขึ้น
* `removeSuffocatedPieces()`: ตรวจสอบหมากที่ถูกทับอยู่ทั้งหมด หากมีหมากตัวใดถูกทับนานเกิน 3 ตา หมากตัวนั้นจะถูกลบทิ้งออกจากอาร์เรย์

### คลาส: Board
จัดการตาราง 3x3 ของออบเจกต์ `Cell` และควบคุมสถานะโดยรวมของกระดาน
* `Board()`: คอนสตรัคเตอร์เริ่มต้นค่าให้กับอาร์เรย์ 3x3 ของคลาส `Cell` ตามพิกัด
* `displayBoard()`: แสดงผลตาราง 3x3 ออกทางหน้าจอคอนโซล โดยวาดเส้นขอบและเรียกใช้เมธอดการแสดงผลของหมากตัวบนสุดในแต่ละช่อง
* `placePiece(const Piece& p, int x, int y)`: ตรวจสอบความถูกต้องของพิกัดและนำหมากตัวใหม่ไปวางลงในช่องที่ระบุ
* `movePiece(int startX, int startY, int endX, int endY, string playerColor)`: จัดการเรื่องการย้ายหมาก โดยจะตรวจสอบพิกัด ตรวจสอบว่าช่องเริ่มต้นมีหมากอยู่ ยืนยันว่าหมากเป็นของผู้เล่นที่กำลังเล่นอยู่ และตรวจสอบว่าสามารถย้ายไปยังช่องปลายทางได้หรือไม่
* `processTurnEndRules()`: เรียกใช้งานเมื่อจบแต่ละตา โดยจะสั่งทำงานเมธอด `updateCoveredPiecesTurn` และ `removeSuffocatedPieces` ให้กับทุกช่องบนกระดาน
* `checkThreeInARow()`: ตรวจสอบกระดานทั้งในแนวนอน แนวตั้ง และแนวทแยง เพื่อดูว่าหมากที่อยู่บนสุดมีสีเดียวกันเรียงต่อกัน 3 ตัวหรือไม่ คืนค่าเป็นสีของผู้ชนะ หรือ "NONE"

### คลาส: Player
จัดการข้อมูลตัวตนของผู้เล่นและคลังหมากที่ยังไม่ได้ถูกใช้งาน
* `Player(string c)`: คอนสตรัคเตอร์สำหรับกำหนดสีของผู้เล่น (X หรือ O) และเตรียมหมากในมือให้พร้อม (ขนาด S 2 ตัว, M 2 ตัว, L 2 ตัว)
* `getColor()`: คืนค่าสีของผู้เล่น
* `displayHand()`: พิมพ์จำนวนหมากที่เหลืออยู่ในมือของผู้เล่นออกทางหน้าจอ
* `hasPiecesInHand()`: คืนค่า true หากผู้เล่นยังมีหมากเหลือให้เล่นอย่างน้อย 1 ตัว
* `playNewPiece(string sizeStr, Board& board, int x, int y)`: แปลงข้อมูลขนาดที่ผู้เล่นพิมพ์เข้ามา ตรวจสอบว่ามีหมากขนาดนั้นเหลืออยู่หรือไม่ และพยายามวางลงบนกระดาน หากสำเร็จจะหักลบจำนวนหมากนั้นออกจากมือ

### คลาส: GameManager
ควบคุมลูปการทำงานหลัก ลำดับตาของผู้เล่น และการตรวจสอบความถูกต้องของการป้อนข้อมูลจากคีย์บอร์ด
* `GameManager()`: คอนสตรัคเตอร์สำหรับตั้งค่า Player X และ Player O พร้อมกำหนดให้ Player X เป็นฝ่ายได้เริ่มก่อน
* `getCoordinates(string promptMsg, int& r, int& c)`: ฟังก์ชันจัดการการป้อนข้อมูลพิกัด โดยจะแสดงข้อความถาม รับค่าข้อความ ตรวจสอบว่าเป็นตัวเลข 2 ตัวในช่วง 0-2 และแปลงค่าไปใส่ในตัวแปรแถว (r) และคอลัมน์ (c) หากพิมพ์ผิดจะแจ้งเตือนให้พิมพ์ใหม่
* `switchTurn()`: สลับตาการเล่นระหว่างผู้เล่น X และ O
* `startGame()`: ลูปการทำงานหลักของเกม ซึ่งมีหน้าที่:
  * ล้างหน้าจอและอัปเดตการแสดงผล UI
  * ตรวจสอบว่าผู้เล่นถูกบังคับให้ย้ายหมากหรือไม่ (ในกรณีที่หมากในมือหมดแล้ว)
  * รับคำสั่งจากผู้เล่นว่าจะเลือกลงหมากใหม่หรือย้ายหมากบนกระดาน
  * เรียกใช้เมธอดของ Board หรือ Player ตามแอคชันที่เลือก
  * ประมวลผลกฎหลังจบตา (หักเวลาหมากที่ถูกทับ)
  * ตรวจสอบเงื่อนไขการชนะ หากมีผู้ชนะให้แสดงผลและจบการทำงานของลูป
